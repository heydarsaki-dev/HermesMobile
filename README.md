# Hermes Mobile — کلاینت اندرویدی هرمس ایجنت

اپلیکیشن اندروید با رابط کاربری کاملاً فارسی و راست‌به‌چپ که مستقیماً به **Hermes Agent**
که روی ترموکس اجرا شده وصل می‌شود.

## معماری

```
📱 Hermes Mobile  ──HTTP/SSE──▶  🔌 Hermes Gateway (Termux)
                                        │
                                        ▼
                                  🤖 AIAgent + ابزارها
                                  (terminal, file, web, vision, …)
```

اپ از سه لایهٔ API هرمس استفاده می‌کند:

| لایه | مسیر | کاربرد |
|------|------|--------|
| OpenAI-compatible | `/v1/chat/completions` | درخواست بدون جریان، ساده و سازگار |
| Runs API | `/v1/runs` + `/events` (SSE) | اجرای ایجنت + رویداد زندهٔ ابزارها |
| Sessions API | `/api/sessions/*` | تاریخچه، جلسات، fork و حذف |

نقاط کشف خودکار: `/v1/health` · `/v1/models` · `/v1/skills` · `/v1/toolsets` · `/v1/capabilities`

## ویژگی‌ها

- **گفت‌وگوی جریانی** با نمایش زندهٔ هر ابزاری که هرمس اجرا می‌کند (نام، مدت، خروجی)
- **پیوست تصویر** (base64 data URL — هرمس آن را به مدل بینایی می‌فرستد)
- **کنترل اجرا**: توقف درخواست در میانهٔ کار
- **تاریخچهٔ کامل جلسات** با بازگشت به جلسهٔ قبلی و حذف
- **تنظیمات جامع**:
  - اتصال: آدرس پایه، کلید Bearer، تست اتصال
  - مدل: انتخاب از مدل‌های کشف‌شده، پرووایدر، سطح استدلال
  - رفتار: پرامپت سیستم، حالت جریانی، Runs API، رویداد ابزارها، طول زمینه
  - ابزارها/مهارت‌ها: فهرست زندهٔ آنچه هرمس در اختیار دارد
  - ظاهر: تم روشن/تاریک/سیستمی، ۸ رنگ تأکیدی، اندازهٔ فونت، جلوهٔ شیشه‌ای، انیمیشن، لرزش لمسی

## ساخت

بیلد از طریق **GitHub Actions** انجام می‌شود:

```bash
git push  # اکشن build.yml به‌طور خودکار اجرا و APK را کامیت می‌کند
```

APK آماده در مسیر `release/HermesMobile-latest.apk` قرار می‌گیرد و
به‌عنوان artifact نیز در دسترس است.

بیلد محلی:

```bash
./gradlew assembleRelease
```

## اتصال

پیش‌فرض روی `http://127.0.0.1:8642` است. برای استفاده:

```bash
# در ترموکس
hermes gateway run
```

کلید API همان `API_SERVER_KEY` است. اگر گیت‌وی روی `0.0.0.0` گوش می‌دهد
می‌توانید از دستگاه دیگری هم با آدرس شبکه وصل شوید.
